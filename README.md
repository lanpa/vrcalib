# vrcalib

Calibrate a Cardboard-style VR viewer by looking through it, then export the
viewer-profile QR code that Cardboard apps scan.

Live site: https://lanpa.github.io/vrcalib/

Not an official Google product. Design notes: [HANDOFF.md](HANDOFF.md).

## Develop

```sh
npm install
npm run dev      # http://localhost:5173/vrcalib/
npm test
npm run build
```
